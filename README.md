# MEGA 本地下载器

## 使用

1. 安装 Node.js 20 或更新版本。
2. 双击 `Open-Downloader.bat`；首次运行会自动安装依赖，之后会启动服务并打开浏览器。
3. 粘贴公开 MEGA 文件或文件夹链接，读取后选择文件旁的连接数（2、4 或 8），再点“下载 / 续传”。

文件保存于本目录的 `downloads` 文件夹。完成文件使用原文件名；若重名，会自动添加序号（如 `文件名 (2).zip`）。连接数较高可能提升速度，也可能更容易触发 MEGA 限流；建议先试 2，网络稳定后再提高。下载时可以按“暂停”，同一个按钮会变成“继续”；断线时会保留 `.part` 临时文件，重新载入同一个分享链接后再次点“下载 / 续传”会从现有长度继续。保持终端窗口和本地服务运行，直到下载完成。

网页底部的“未完成下载”会列出临时文件、已占用空间和最后修改时间。旧版本留下的临时文件可能无法识别原文件名，但仍可查看占用空间并删除。删除会释放临时文件空间，同时失去该文件的续传进度。

文件夹链接读取后，文件列表可以点击展开或收起；超过 20 个文件时默认收起。搜索框留在列表上方，输入文件名即可筛选。

服务只绑定本机回环地址 `127.0.0.1`。此版本面向公开分享链接；不支持登录 MEGA 账户、绕过配额或保证突破 MEGA、ISP 的限速。大文件续传是否成功取决于 MEGA 仍允许该链接访问及其下载配额。
